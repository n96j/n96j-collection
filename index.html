How to download (3 clicks)

  1. Open Downloads and choose the Windows.
  2. Choose Official, Beta or Modded, then your language.
  3. Press Download. The file comes from archive.org.
Tip: or just type in the search box (for example “xp portuguese”).
Note: this site hosts no files. It only organizes public links to archive.org. Please respect each software’s license.
